# 🌸 DanizTori Instagram Bio Link Web Application

پروژه وبسایت فوق‌العاده مدرن و زیبا برای لینک‌های بیو اینستاگرام **DanizTori**.

![DanizTori Avatar](assets/avatar.png)

## ✨ امکانات پروژه (Features)

- 🎨 **طراحی Glassmorphism پرمیوم:** استفاده از گرادینت‌های شیک، افکت‌های شیشه‌ای، و انیمیشن‌های نرم.
- 🌓 **تم تاریک و روشن (Dark / Light Mode):** با قابلیت ذخیره‌سازی انتخاب کاربر در LocalStorage.
- 📱 **کاملاً واکنش‌گرا (Responsive):** بهینه‌شده برای موبایل، تبلت و دسکتاپ.
- 🔗 **لینک‌های سریع شبکه‌های اجتماعی:** اینستاگرام، تلگرام، یوتیوب، واتساپ، اسپوتیفای و ایمیل.
- 📷 **کد QR اختصاصی:** امکان اسکن سریع با موبایل و اشتراک‌گذاری مستقیم.
- 📊 **شمارنده آمار و کلیک‌ها:** نمایش آمار کلیک‌ها و بازدید به صورت زنده.
- 📋 **کپی سریع لینک:** کلید کپی لینک همراه با اعلان Toast.

## 🚀 راهنمای ساخت ریپازیتوری در گیت‌هاب اکانت `masoumasoud@gmail.com`

برای قرار دادن این پروژه روی گیت‌هاب خود، می‌توانید از یکی از روش‌های زیر استفاده کنید:

### روش ۱: استفاده از سایت GitHub (ساده‌ترین روش)

1. وارد سایت [GitHub.com](https://github.com) شوید و با اکانت `masoumasoud@gmail.com` لاگین کنید.
2. روی دکمه **New Repository** (یا علامت + در بالای صفحه) کلیک کنید.
3. نام ریپازیتوری را قرار دهید: `daniztori-instagram-bio-link`
4. حالت آن را روی **Public** قرار داده و روی **Create repository** کلیک کنید.
5. فایل‌های این پوشه (`index.html`, `styles.css`, `app.js`, `README.md` و پوشه `assets`) را در ریپازیتوری آپلود کنید (از طریق دکمه Uploading an existing file).

### روش ۲: استفاده از دستورات Git در ترمینال

در صورت نصب بودن Git روی سیستم خود، دستورات زیر را اجرا کنید:

```bash
git init
git add .
git commit -m "Initial commit for DanizTori Bio Link web app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/daniztori-instagram-bio-link.git
git push -u origin main
```

## 🌐 انتشار رایگان روی وب (GitHub Pages)

پس از ساخت ریپازیتوری در گیت‌هاب:
1. به تب **Settings** ریپازیتوری بروید.
2. از منوی سمت چپ گزینه **Pages** را انتخاب کنید.
3. در بخش **Source**، شاخه `main` را انتخاب کرده و روی **Save** کلیک کنید.
4. آدرس وبسایت شما بعد از چند ثانیه آماده خواهد شد (مثلاً: `https://YOUR_USERNAME.github.io/daniztori-instagram-bio-link/`) که می‌توانید آن را مستقیماً در بیو اینستاگرام **DanizTori** قرار دهید!
